# Major 15.0 Migration guide

> [!IMPORTANT]
> Please make sure to first follow the ["Upgrade new version guide"](https://github.com/AmadeusITGroup/otter/blob/main/docs/core/UPGRADE_NEW_VERSION.md) before going through these steps.

## Renovate task configuration

The Renovate shared tasks (`sdk-spec-regenerate-with-auth`, `sdk-regenerate-with-auth`, `otter-ng-update-with-auth`, `base-with-auth`) no longer include an install fallback in the `{{else}}` branch of the authentication conditional commands.

Previously, when no registry arguments were provided, the `{{else}}` branch would execute an extra install command (e.g. `{{arg0}} install` or `{{{depName}}} install`). This was redundant because the install command already runs unconditionally later in the task.

**Action required:** If your Renovate bot uses an `allowedPostUpgradeCommands` allowlist, you no longer need to allow the standalone install commands that were previously emitted by the `{{else}}` branches. No other configuration change is needed — the tasks now simply skip authentication setup when registry arguments are empty.
