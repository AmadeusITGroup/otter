# ama-styling

AI-powered skills for design token usage, styling best practices, and configuring the `@ama-styling/mcp` server so AI assistants can discover and recommend design tokens from your project's token library.

## Skills

| Skill | Description |
|-------|-------------|
| **styling-mcp-setup** | Install and configure the `@ama-styling/mcp` server for AI-assisted design token discovery |
| **styling-best-practices** | Token-first development guidelines, Otter extensions, naming conventions, and component styling patterns |

## Installation

**Claude Code** (CLI or VS Code extension):

```
/plugin marketplace add AmadeusITGroup/otter
/plugin install ama-styling
```

**GitHub Copilot in VS Code** — either:

- Run **Chat: Install Plugin From Source** from the Command Palette and enter this repository's URL, or
- Add the marketplace to your user `settings.json` so plugins stay discoverable:

  ```json
  "chat.plugins.marketplaces": {
    "AmadeusITGroup/otter": true
  }
  ```

The same [`.claude-plugin/`](../../../../.claude-plugin/marketplace.json) manifest is recognized by both tools — see VS Code's [agent plugins documentation](https://code.visualstudio.com/docs/copilot/customization/agent-plugins) for the format-detection rules.

## Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- A project with a `styling.metadata.json` file generated by [`@ama-styling/style-dictionary`](https://www.npmjs.com/package/@ama-styling/style-dictionary) using the `ama/json/metadata` format

## Contributing

To add a new skill:
1. Create a subdirectory in `skills/` with a `SKILL.md` file
2. Add YAML frontmatter with `name` and `description` fields
3. Follow existing skill structure (Prerequisites, Configuration, Examples sections)
4. Update the skills table in this README
5. Add the skill to `collections/ama-styling.collection.yml`
